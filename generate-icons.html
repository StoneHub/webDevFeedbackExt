Instructions:

  1. Click "Download All Icons" above (or download individually)
  2. Save each icon with its correct filename:
    • icon16.png
    • icon48.png
    • icon128.png
  3. Place all three icon files in the webDevFeedbackExt folder
  4. Reload the extension in Chrome

Note: If you prefer the terminal, you can also run scripts/generate-icons.ps1 to regenerate all three files.
